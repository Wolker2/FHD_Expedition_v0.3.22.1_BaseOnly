FHD_Expedition — RuinsTalk Intro 0.3.27

Изменение по пользовательскому скриншоту:
- нижняя графическая кнопка экспедиций остаётся на прежнем месте;
- после нажатия описание выводится в верхнем штатном текстовом поле RuinsTalk;
- «Продолжить» и «Отказаться» выводятся штатными ответами в нижнем списке диалога;
- отдельное MessageBox/ListBox для вступительного текста не используется;
- GUI-код больше не обращается к GAnswerData; вместо этого используется одноразовая скрытая CustomShipInfo-метка;
- «Продолжить» запускает исходный Script.FHDExpedition.Open;
- «Отказаться» возвращает обычный диалог базы;
- исходный FHD_Expedition.scr и FHDExpeditionNative.dll не изменены.
