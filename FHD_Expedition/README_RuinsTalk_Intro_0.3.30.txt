FHD_Expedition v0.3.30 — RuinsTalk FormChange Fix

Исправление относительно 0.3.29:
- DAnswer('restart') удалён из обработчика нижней GUI-кнопки Expeditions: эта функция предназначена для кода настоящего DialogAnswer и при вызове из GraphButton приводит к Access Violation.
- После установки одноразового скрытого флага выполняется FormChange('RuinsTalk'), то есть штатный перезаход в текущую форму станции.
- При повторном входе DialogBegin вспомогательного SCR видит флаг, удаляет его и добавляет описание в верхнее поле штатного разговора и ответы «Продолжить» / «Отказаться» в нижний список.
- основной FHD_Expedition.scr, FHDExpeditionNative.dll, Lang.dat и логика экспедиций не изменены относительно 0.3.29.
